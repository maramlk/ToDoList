# 📋 My Productivity Dashboard
A responsive and interactive web-based productivity tool built with HTML, CSS, and JavaScript, designed to help users manage tasks, visualize deadlines on a calendar, and maintain focus using a built-in Pomodoro timer.

✨ Features
- To-Do ListAdd, complete, and delete tasks with optional due dates and times.
- FullCalendar IntegrationTasks with due dates appear automatically on an interactive calendar.
- Pomodoro Timer25-minute focus sessions with automatic 5-minute breaks, including start/pause/reset controls.
- Dark Mode ToggleSwitch between light and dark themes. Preference is saved using localStorage.
- Color Palette SwitcherChoose between purple, green, blue, and orange themes. Accent color and gradient background update dynamically.
- Data PersistenceTasks and theme settings are saved across sessions using localStorage.



Technologies Used
- HTML5
- CSS3 with CSS Variables and Grid Layout
- JavaScript (Vanilla)
- FullCalendar.js for interactive calendar integration
